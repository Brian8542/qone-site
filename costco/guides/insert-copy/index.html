01창고형 매장 삽지(인서트 카피)란

창고형 매장 삽지는 포장 안에 넣거나 투명 포장 뒤에 끼워 회원이 제품 정보를 읽을 수 있게 만든 인쇄물입니다. 업계에서는 인서트 카드, 인서트 카피라고도 부르며, 띠지·스티커·박스 인쇄 문구와 함께 '패키지 문구'로 묶어 관리하는 경우가 많습니다.

창고형 매장은 일반적으로 판매 직원이 상품을 일일이 설명하지 않습니다. 회원은 팔레트 앞에서 포장을 보고 몇 초 안에 담을지 말지 결정합니다. 그래서 문구는 길고 화려하기보다 '무엇이고, 얼마나 크고, 몇 개 들었고, 왜 좋은지'가 바로 보여야 합니다.

형태위치주로 쓰는 경우
인서트 카드(삽지)투명 포장 안, 제품 뒤제품이 보이는 포장에 설명을 더할 때
포장 인쇄 문구판매 포장 겉면박스형 판매 포장
띠지제품이나 묶음 상품 둘레국가별 문구를 바꾸거나 묶음을 고정할 때
스티커포장 특정 위치수입자 정보 등 국가별 추가 표기
삽지 형태, 표기 항목, 언어 수, 위치는 국가·바이어·카테고리별로 다를 수 있습니다. 바이어가 양식이나 가이드를 주는 경우가 많으므로 인쇄 전에 반드시 확정본을 받아 확인하십시오.

03다국어 표기 정리 방법

창고형 매장은 국가별로 운영되므로 판매국 언어 표기가 기본입니다. 한 포장으로 여러 국가에 대응하려고 언어를 많이 넣으면 글씨가 작아지고 핵심이 묻힙니다. 판매국 언어를 크게, 나머지는 보조로 두거나 띠지·스티커로 국가별 문구를 바꾸는 방식이 실무에서 자주 쓰입니다.

방식장점유의점
판매국 전용 포장정보가 크고 명확함국가마다 포장을 따로 생산
다국어 병기 포장한 포장으로 여러 국가 대응글씨가 작아지고 핵심이 묻힘
공통 포장 + 국가별 띠지·스티커포장 재고를 공유하면서 문구만 교체부착 작업 공정과 위치 관리 필요
  1. 한국어 원문 확정제품 정보와 특징을 한국어로 먼저 정리하고 내부 확인을 끝냅니다.
  2. 판매국 언어 번역기계 번역 결과를 그대로 쓰지 말고 현지어 검수를 거칩니다.
  3. 법정 표기 대조판매국에서 요구하는 표시 항목이 빠지지 않았는지 대조합니다.
  4. 바이어 검토디자인 시안에 문구를 앉힌 상태로 바이어 확인을 받습니다.
  5. 인쇄 교정인쇄 직전 숫자·단위·바코드를 마지막으로 대조합니다.

원산지·라벨 규정은 라벨·원산지 표시 가이드에서 국가별로 정리했습니다.

04읽히는 문구를 쓰는 요령

창고형 매장의 회원은 팔레트 앞을 지나가며 포장을 훑어봅니다. 문장은 짧게 끊고, 한 줄에 하나의 정보만 담는 것이 좋습니다. 특징은 형용사보다 숫자와 사실로 표현해야 신뢰를 얻습니다. '아주 큰 매트'보다 '200×150cm'가, '넉넉한 구성'보다 '2롤 세트'가 더 빨리 이해됩니다.

숫자를 앞에크기·수량·두께 같은 숫자를 문장 앞쪽에 둡니다.
그림으로 대신사용법과 주의사항은 아이콘이나 그림을 함께 씁니다.
앞면은 세 줄앞면에는 제품명, 핵심 특징, 규격·구성만 크게 넣습니다.
뒷면은 정보소재, 사용법, 주의사항, 원산지, 표시자 정보는 뒷면에 정리합니다.

문구를 다 쓴 뒤에는 포장 시안을 2~3m 떨어진 곳에 세워 두고 읽어 보십시오. 그 거리에서 제품명과 크기가 읽히지 않으면 글씨 크기나 정보량을 다시 조정해야 합니다.

05자주 하는 실수

  • 포장 문구와 제품 실제 치수·수량이 다름(사양 변경 후 문구 미수정)
  • 같은 포장 안에서 cm·mm·inch 단위가 섞여 있음
  • 한국어 문구를 그대로 번역해 현지에서 어색하거나 뜻이 바뀜
  • 근거 자료 없는 기능 표현(항균, 친환경 등)을 넣음
  • 주의사항·원산지 같은 필수 항목이 디자인 과정에서 빠짐
  • 박스 바코드와 판매 단위 바코드를 혼동해 인쇄함
  • 띠지 문구와 본 포장 문구가 서로 다른 내용을 말함

이런 실수는 대부분 문구를 디자인 파일 안에서만 관리할 때 생깁니다. 문구를 표(스프레드시트)로 먼저 정리하고, 디자인은 그 표를 그대로 옮기는 방식으로 관리하면 수정 누락을 크게 줄일 수 있습니다.

또 하나 흔한 문제는 국내 상세페이지 문구를 그대로 줄여 쓰는 경우입니다. 온라인 문구는 스크롤하며 읽는 것을 전제로 길게 쓰여 있어, 매장 포장에 옮기면 핵심이 흐려집니다. 매장용 문구는 처음부터 '서서 몇 초 안에 읽는 글'로 다시 쓰는 것이 좋습니다.

사양이 바뀔 때마다 문구 표를 먼저 고치고, 그다음 디자인 파일을 고치는 순서를 지키면 포장과 실제 제품이 어긋나는 일을 막을 수 있습니다.

06인쇄 전 최종 점검 표

패키지 문구는 한 번 인쇄하면 수정하기 어렵고, 오류가 발견되면 스티커 작업이나 재인쇄로 이어집니다. 인쇄 직전에는 디자인 담당과 별도로 다른 사람이 아래 항목을 원본 자료와 하나씩 대조하는 것이 좋습니다.

점검 항목대조 기준확인 방법
치수·무게최신 제품 사양서숫자와 단위를 한 글자씩 대조
구성 수량실제 포장 샘플샘플을 열어 개수 확인
바코드발급 등록 정보스캐너로 읽어 품번 일치 확인
원산지·표시자판매국 표시 기준바이어 확인본과 대조
번역 문구현지어 검수본검수 후 수정 사항 반영 여부 확인
주의사항시험 성적서·제품 특성필수 안전 문구 누락 여부 확인

점검이 끝난 최종 파일에는 날짜와 버전 번호를 붙여 보관합니다. 재발주 때 문구를 바꾸게 되면 이전 버전과 무엇이 달라졌는지 바로 확인할 수 있어 같은 실수를 반복하지 않게 됩니다.

07큐원 사례: 일본 창고형 매장 캠핑매트 띠지와 가격표

큐원은 2025년 12월 일본 창고형 매장용 캠핑매트의 PDQ 전개도와 띠지 디자인을 직접 제작했습니다. 2026년 3월 일본 창고형 매장에서는 매장 패키지와 2,180엔 가격표가 붙은 모습이 촬영되었습니다. 매장에서는 포장 문구와 가격표가 나란히 보이므로, 제품명과 규격이 가격표 정보와 어긋나지 않게 맞추는 것이 중요합니다.

진열 박스와 띠지를 함께 설계하는 과정은 PDQ·진열 박스 설계에서 이어서 볼 수 있습니다.

08문구 작성 전 준비할 자료

  • 제품 사양서(치수·무게·재질·구성)
  • 시험 성적서와 인증서 사본(특징 문구 근거)
  • 기존 국내 판매 포장 파일과 상세페이지 문구
  • 사용법을 보여 줄 사진이나 그림 초안
  • 판매 희망 국가 목록

문구 초안이 없어도 괜찮습니다. 큐원 해외유통 사업팀이 사양서와 기존 자료를 바탕으로 판매국 기준의 문구 구성을 함께 검토합니다. 제안서 작성 가이드를 참고해 자료를 chl@qone.kr로 보내 주십시오.

자주 묻는 질문

모든 상품에 필요한 것은 아닙니다. 포장 겉면 인쇄로 충분한 경우도 있고, 바이어가 별도 삽지를 요청하는 경우도 있어 국가·바이어·카테고리별로 확인이 필요합니다.

판매국 언어가 기본입니다. 여러 국가에 같은 포장을 쓰려면 띠지나 스티커로 국가별 문구를 바꾸는 방식을 검토하십시오.

기계 번역 초안을 쓰더라도 현지어 검수를 거치는 것이 안전합니다. 최종 문구는 바이어 확인을 받는 것이 일반적입니다.

판매국 표시 항목과 언어, 구성 단위가 달라 그대로 쓰기 어려운 경우가 많습니다. 기존 포장을 기준으로 수정 범위를 정하면 됩니다.
