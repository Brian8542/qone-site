Политика конфиденциальности

Дата вступления в силу: 1 июля 2026 г.

주식회사 큐원 (далее — «Компания») соблюдает Закон Республики Корея «О защите персональных данных» и иные применимые нормативные акты и бережно относится к персональным данным пользователей. Настоящая политика определяет порядок обработки персональных данных, собираемых через веб-сайт Компании (qone.kr).

1. Состав собираемых персональных данных и способы их сбора

Компания собирает перечисленные ниже данные через форму обратной связи (деловой запрос); данные вводятся пользователем самостоятельно.

Собираемые данныеИмя (или наименование компании), адрес электронной почты, содержание запроса (товар, количество, целевой рынок и т. п.)
Способ сбораСамостоятельный ввод в форму обратной связи на сайте (данные пересылаются по электронной почте через сервис Web3Forms)
Автоматически собираемые данныеОтсутствуют — статистика посещений собирается только в анонимном и обобщённом виде с помощью сервиса Cloudflare Web Analytics, который не сохраняет файлы cookie и персональные данные.

2. Цели сбора и использования персональных данных

  • Ответы на деловые запросы (консультации по продукции, расчёт цены, переговоры об экспорте и импорте и т. п.) и деловая переписка
  • Поддержание деловых отношений и последующее сопровождение

3. Сроки хранения и использования персональных данных

Персональные данные, полученные через запросы, подлежат незамедлительному уничтожению после достижения целей ответа на запрос и поддержания деловых отношений. Если же их хранение требуется в соответствии с применимым законодательством, они хранятся в течение срока, установленного соответствующим законом.

4. Передача персональных данных третьим лицам

Компания, как правило, не передаёт персональные данные пользователей третьим лицам. Однако для отправки формы обратной связи используется сервис отправки электронной почты (Web3Forms); введённые вами данные используются исключительно для пересылки через этот сервис на адрес электронной почты Компании (chl@qone.kr).

5. Поручение обработки персональных данных

ОбработчикWeb3Forms
Поручаемые функцииПересылка данных формы обратной связи сайта по электронной почте

6. Права пользователей и порядок их осуществления

Пользователь вправе в любое время запросить доступ к своим персональным данным, их исправление, удаление или приостановку обработки. Обратитесь по указанным ниже контактам — мы незамедлительно примем меры.

7. Использование файлов cookie

Для сбора статистики посещений сайт использует Cloudflare Web Analytics. Этот инструмент не использует файлы cookie и не сохраняет сведения, позволяющие идентифицировать личность, в том числе IP-адреса; это инструмент аналитики, ориентированный на защиту конфиденциальности.

8. Меры по обеспечению безопасности персональных данных

Для защиты персональных данных Компания применяет организационные меры (в том числе минимизацию прав доступа) и обрабатывает данные только с помощью надёжных сервисов (Web3Forms, Cloudflare).
